Privacy Policy

Effective date: October 20, 2026

Biolifer Video Publisher ("the tool") is a private desktop script used by the owner of the YouTube channel Biolifer to upload the owner's own videos to that channel.

YouTube API Services

The tool uses YouTube API Services. Use of the tool is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy) and the YouTube Terms of Service.

What information the tool accesses

  • Google sign-in token. The tool signs in with Google OAuth 2.0 and requests only the https://www.googleapis.com/auth/youtube.upload permission, which allows uploading videos and setting their thumbnails. It cannot read, edit or delete other videos, comments, subscribers, analytics or any other account data.
  • The owner's own video files, titles, descriptions and thumbnails, which are sent to YouTube during upload.
  • The upload response from YouTube (the ID of the new video), used to open and check the published video.

How the information is used, stored and shared

  • The sign-in token is stored only in a local file on the owner's own computer. It is not sent anywhere except to Google.
  • Videos and their titles, descriptions and thumbnails are sent only to YouTube, through YouTube API Services.
  • The tool does not collect, sell or share personal information with any third party. It does not store YouTube data beyond the IDs of the owner's own uploaded videos, and it does not use analytics, advertising or tracking.
  • The tool does not access information from other people's accounts.

Cookies and device information

The tool is a desktop script. It does not place cookies and does not store or read information on any device other than its own local token file on the owner's computer. This website does not use cookies or analytics.

How to revoke access and delete data

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Deleting the local token file removes all data stored by the tool. After access is revoked, the token can no longer be used.
  • To ask a question or request deletion, write to my.life.prestige@gmail.com. Requests are answered within 7 days.

Changes

If this policy changes, the new version will be published on this page with a new effective date.

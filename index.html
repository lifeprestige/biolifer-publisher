Biolifer Video Publisher

A private desktop tool that uploads my own short educational videos to my own YouTube channel, Biolifer.

This application uses YouTube API Services.

By using it you agree to be bound by the YouTube Terms of Service. How data is handled: the Privacy Policy of this tool and the Google Privacy Policy.

What it does

  • I film and edit each video myself. When a video is ready, the tool uploads it to my channel with the title, description and thumbnail I prepared.
  • It uses only two YouTube API methods: videos.insert (upload) and thumbnails.set (custom thumbnail).
  • It signs in with Google OAuth 2.0 and asks only for the youtube.upload permission.

How it works

End-to-end demo (sign-in, permission, upload, result, revoking access): demo video (53 s).

Who can use it

Only the owner of the Biolifer channel. The tool runs on the owner's own computer. It is not offered to other people, has no public sign-up and does not access anyone else's account or data.
